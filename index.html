💡 Comment installer et utiliser ?
Sur PC Windows
Cliquez sur le bouton bleu pour télécharger DBDMaps.exe. Double-cliquez dessus pour lancer le logiciel immédiatement. Aucune installation compliquée !

Cliquez sur le bouton vert depuis votre téléphone pour télécharger DBDMaps.apk. Ouvrez le fichier téléchargé et validez l'installation.
Jouer en Équipe (Lobby)
Dans l'onglet Lobby, l'un des joueurs crée un code (ex: ABC12) et les autres le rejoignent. Dès qu'un joueur clique sur une carte, elle change chez tout le monde !
